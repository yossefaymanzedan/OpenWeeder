Decisions

Steps

Rules that apply to every step

  • Never print, log or commit .env.
  • Never connect anything to the pump GPIO except a bench LED with a resistor.
  • Do not change tools/planner.py or tools/geometry.py behaviour; all existing tests must keep passing. Do not edit the tests.
  • Everything that touches hardware goes through Hardware. The simulator and the real robot run the same planner.
  • Never spray a crop. Crop hits must be 0; if not, stop and find the cause.
  • Ask before anything that costs API money.
  • Report honestly: misses, crop hits, anything that failed.
